How it works

From template to generated TIA Portal project code.

The engineer works with clear parameter tables, and MetaPlatform converts them into Siemens PLC code, settings, HMI tags, and alarms.

01

Choose a template

Choose the required standard unit from the template library. For example: VFD motor, PID regulator, valve, sensor, or alarm block.

02

Fill parameters

Fill in IDs, equipment names, inputs, outputs, regulator parameters, alarms, and generation settings.

03

Generate code

One template generates ready Siemens PLC code: block calls, instance DBs, settings, HMI tags, and alarms.
